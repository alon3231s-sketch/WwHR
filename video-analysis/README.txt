ניתוח וידאו עם קלוד - סקיל להתקנה
====================================

מה זה?
קלוד לא יודע לנגן סרטונים. הסקיל הזה מלמד אותו "לצפות" בכל זאת:
הוא מפרק את הסרטון לתמונות, קורא כתוביות מהמסך, מנתח סגנון ומוציא
מידע על הקובץ. בפעם הראשונה קלוד גם יתקין בשבילכם (בליווי מלא)
כלי חינמי בשם ffmpeg שעושה את העבודה הטכנית.

איך מתקינים את הסקיל? (3 צעדים)
1. חלצו את הקובץ שהורדתם (קליק ימני > Extract All / חלץ הכל).
2. העתיקו את התיקייה video-analysis לתוך תיקיית הסקילים של קלוד:
   בווינדוס:  C:\Users\<שם המשתמש שלכם>\.claude\skills
   במק:       /Users/<שם המשתמש שלכם>/.claude/skills
   (אם תיקיית skills לא קיימת - פשוט צרו אותה)
3. סגרו ופתחו מחדש את Claude Code.

איך משתמשים?
כותבים לקלוד בשפה חופשית, למשל:
   "מה יש בסרטון שנמצא בהורדות בשם lecture.mp4?"
   "תקרא לי את הכתוביות מהסרטון הזה"
   "מה הסגנון של הכתוביות בסרטון?"

בפעם הראשונה קלוד יציע להתקין את ffmpeg - תגידו כן ותנו לו לעבוד
(לוקח 5-10 דקות, פעם אחת בלבד). מהפעם השנייה הוא ניגש ישר לניתוח.

בהצלחה!
איילון
