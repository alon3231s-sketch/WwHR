# מתכוני ניתוח - כל הפקודות

כל המתכונים נבדקו בעבודה אמיתית. `ffmpeg`/`ffprobe` בפקודות = הערכים מ-state.json (אם שם שמור נתיב מלא - להשתמש בו).

**כלל נתיבים בווינדוס:** בסקריפטים של node ובפקודות, לכתוב נתיבים בסגנון `C:/Users/...` (קו נטוי קדימה). נתיבים בסגנון `/c/Users/...` עובדים ב-bash אבל שוברים סקריפטים של node.

**קבצים זמניים:** הכל נשמר לתיקייה זמנית, אף פעם לא לתיקיית העבודה של המשתמש. `$SCRATCH` בפקודות הוא לא משתנה מוגדר מראש - להגדיר אותו בתחילת **כל** פקודת bash (מצב השל לא נשמר בין פקודות):

```bash
SCRATCH="${TMPDIR:-$HOME/AppData/Local/Temp}/video-analysis"; mkdir -p "$SCRATCH"
```

---

## מתכון 1 - ffprobe: מה יש בקובץ (תמיד ראשון)

```bash
ffprobe -v error -show_entries format=duration,bit_rate -show_entries stream=index,codec_type,codec_name,width,height,r_frame_rate,sample_rate,channels -of default=noprint_wrappers=1 "VIDEO.mp4"
```

מה מחפשים בפלט:
- `duration` - קובע את צפיפות הפריימים (מתכון 2)
- `codec_type=video` + `width/height` - רזולוציה (משפיעה על חיתוך הכתוביות)
- `codec_type=audio` - האם יש בכלל אודיו
- מסלול שלישי מסוג subtitle - נדיר, אבל אם קיים אפשר לחלץ כתוביות כטקסט ישירות: `ffmpeg -i VIDEO.mp4 -map 0:s:0 subs.srt`

## מתכון 2 - פריימים כלליים: "מה יש בסרטון"

צפיפות לפי אורך (המטרה: 12-25 תמונות סה"כ):

| אורך הסרטון | פרמטר fps |
|---|---|
| עד דקה | `fps=1/3` (פריים כל 3 שניות) |
| 1-5 דקות | `fps=1/10` |
| 5-20 דקות | `fps=1/40` |
| מעל 20 דקות | `fps=1/120`, ואם צריך פירוט - ריצה שנייה ממוקדת על קטע |

```bash
mkdir -p "$SCRATCH/frames"
ffmpeg -v error -i "VIDEO.mp4" -vf "fps=1/3,scale=960:-1" -q:v 3 "$SCRATCH/frames/f_%02d.jpg" -y
ls "$SCRATCH/frames"
```

ואז לקרוא את התמונות בכלי Read, **עד 3 בכל קריאה**. לחישוב הזמן של פריים: מספר הפריים כפול המרווח (f_05 עם fps=1/3 = שנייה ~15).

לקטע ממוקד (מהר יותר מסריקה מלאה): `-ss` לפני `-i`:
```bash
ffmpeg -v error -ss 45 -i "VIDEO.mp4" -frames:v 1 -q:v 2 "$SCRATCH/at_45s.jpg" -y
```

## מתכון 3 - כתוביות צרובות: תמלול מהמסך

הרעיון: חותכים רק את רצועת הכתוביות, זורקים פריימים כפולים (אותה כתובית מוצגת שניות), ומדביקים את מה שנשאר ללוחות אנכיים שקוראים כמו דף.

### שלב א - איפה הכתוביות? פריים מלא אחד

```bash
ffmpeg -v error -ss 10 -i "VIDEO.mp4" -frames:v 1 -q:v 2 "$SCRATCH/probe_frame.jpg" -y
```

לקרוא את התמונה ולהעריך את גבולות רצועת הכתוביות בפיקסלים. נקודת פתיחה טובה ל-720p עם כתוביות תחתונות: `crop=iw:200:0:485` (רוחב מלא, 200px גובה, מ-y=485). להתאים לפי מה שרואים.

### שלב ב - חילוץ עם סינון כפולים

```bash
mkdir -p "$SCRATCH/subs"
ffmpeg -v error -i "VIDEO.mp4" -vf "crop=iw:200:0:485,fps=3,mpdecimate=hi=64*200:lo=64*80:frac=0.5,setpts=N/FRAME_RATE/TB,scale=800:-1" -q:v 2 "$SCRATCH/subs/s_%03d.jpg" -y
ls "$SCRATCH/subs" | wc -l
```

- `fps=3` - שלוש דגימות בשנייה, מספיק כדי לא לפספס כתובית קצרה
- `mpdecimate` עם הפרמטרים האלה - זורק פריימים שכמעט זהים לקודמם. בבדיקה אמיתית צמצם 148 פריימים ל-54
- אם נשארו יותר מ-80 פריימים לדקת וידאו - להקשיח את `frac` (למשל 0.7); אם נראה שכתוביות נעלמו - לרכך (0.3)

### שלב ג - הדבקה ללוחות

```bash
ffmpeg -v error -i "$SCRATCH/subs/s_%03d.jpg" -vf "tile=1x6:margin=4:padding=4" -q:v 2 "$SCRATCH/sheet_%02d.jpg" -y
```

כל לוח = 6 שורות כתוביות. לקרוא את הלוחות לפי הסדר ולהרכיב תמלול רציף. שאריות כפולים (אותה שורה פעמיים ברצף) - לקרוא פעם אחת.

**חשוב לדעת:** אם שמות הקבצים לא רציפים (למשל אחרי מחיקה ידנית), ffmpeg ייכשל על הרצף. לתקן במספור מחדש:
```bash
cd "$SCRATCH/subs" && n=1; for f in s_*.jpg; do mv "$f" "$(printf 'r_%03d.jpg' $n)"; n=$((n+1)); done
```

### שלב ד - חורים בתמלול

אם יש קפיצה לא הגיונית בין שני לוחות - לחלץ פריימים בודדים מהשניות החסרות (`-ss` + `-frames:v 1` עם אותו crop) ולהשלים.

### וריאציה - כתוביות של קטע זמן מסוים

כשהמשתמש שואל "מה כתוב בין שנייה X ל-Y" - לא מעבדים את כל הסרטון. מוסיפים חלון זמן **לפני** ה-`-i` (מהיר) ומריצים את אותו פילטר בדיוק:

```bash
ffmpeg -v error -ss 20 -t 10 -i "VIDEO.mp4" -vf "crop=iw:200:0:485,fps=3,mpdecimate=hi=64*200:lo=64*80:frac=0.5,setpts=N/FRAME_RATE/TB,scale=800:-1" -q:v 2 "$SCRATCH/subs20_30/s_%03d.jpg" -y
```

חשוב לדעת: אחרי `mpdecimate,setpts` מספרי הפריימים בפלט **כבר לא מייצגים זמן** - הדרך היחידה לשייך כתובית לשנייה היא לחלץ עם חלון זמן כמו כאן, או פריים בודד עם `-ss`.

### שתי שפות שלא מסונכרנות

בכתוביות דו-לשוניות (עברית + אנגלית) קורה שהשורות לא מתחלפות באותו רגע - שפה אחת "מקדימה" את השנייה בפריים מסוים. לתמלל כל שפה כרצף עצמאי, לא לנסות ליישר שורה מול שורה. אם המשתמש צריך שפה סמכותית - שפת הדיבור באודיו היא המקור, והכתוביות הן תרגום.

## מתכון 4 - ניתוח סגנון: פונטים, צבעים, מיקומים

כשרוצים לשחזר או לתאר סגנון (כתוביות, לוגו, גריידינג):

```bash
# פריים מלא באיכות מקסימלית
ffmpeg -v error -ss 27 -i "VIDEO.mp4" -frames:v 1 -q:v 1 "$SCRATCH/style_full.jpg" -y
# זום x2.5 על אזור הכתוביות (חד, בלי מריחה)
ffmpeg -v error -ss 27 -i "VIDEO.mp4" -frames:v 1 -vf "crop=1000:200:140:480,scale=2500:-1:flags=lanczos" -q:v 1 "$SCRATCH/style_zoom.jpg" -y
```

מהזום אפשר לזהות: משקל פונט (בולד/רגיל), קונטור/צל, האם יש רקע לטקסט, יחסי גדלים בין שפות.

### מדידה מדויקת בפיקסלים (מתקדם)

כשצריך מספרים מדויקים (גובה שורה, מיקום, צבע רקע) - מחלצים פריים גולמי ומודדים עם node:

```bash
ffmpeg -v error -ss 27 -i "VIDEO.mp4" -frames:v 1 -pix_fmt rgb24 -f rawvideo "$SCRATCH/frame.raw" -y
```

```bash
node -e "
const fs=require('fs');const b=fs.readFileSync(process.argv[1]);const W=1280,H=720; // מהרזולוציה של ffprobe
const px=(x,y)=>{const i=(y*W+x)*3;return [b[i],b[i+1],b[i+2]]};
// דוגמה: איתור שורות טקסט לבן בשליש התחתון
let rows=[];
for(let y=Math.floor(H*0.65);y<H;y++){let c=0;for(let x=100;x<W-100;x++){const[r,g,bl]=px(x,y);if(r>195&&g>195&&bl>195)c++}if(c>6)rows.push(y)}
console.log('שורות עם טקסט לבן:',rows.length?rows[0]+'-'+rows[rows.length-1]:'לא נמצאו');
console.log('צבע בנקודה (600,60):',px(600,60));
" "$SCRATCH/frame.raw"
```

להעביר את הנתיב כארגומנט (כמו למעלה) ולא בתוך המחרוזת - חוסך בעיות נתיבים בווינדוס.

## מתכון 5 - חילוץ אודיו

מכין קובץ בפורמט שכלי תמלול מצפים לו (16kHz מונו WAV):

```bash
ffmpeg -v error -i "VIDEO.mp4" -ac 1 -ar 16000 -c:a pcm_s16le "$SCRATCH/audio.wav" -y
```

**מגבלה שאומרים למשתמש ביושר:** הסקיל הזה לא כולל כלי תמלול דיבור. אם יש כתוביות צרובות - מתכון 3 נותן תמלול מלא בלי שום כלי נוסף. אם אין - קובץ ה-WAV מוכן, והמשתמש יכול להעלות אותו לכלי תמלול (או שקלוד יציע להתקין אחד - פרויקט נפרד).

## מתכון 6 - מטא-דאטה: מאיפה הקובץ הזה

```bash
ffprobe -v error -show_format -of default=noprint_wrappers=1 "VIDEO.mp4"
```

ה-tags בפלט מגלים encoder, תאריכים, ולפעמים את הכלי שיצר.

חלק מהקבצים (במיוחד מ-Canva, פרימיירה, ומודעות) מחביאים XMP בתוך קופסת uuid ש-ffprobe לא מציג. בדיקה משלימה:

```bash
node -e "
const fs=require('fs');const b=fs.readFileSync(process.argv[1]);
const s=b.toString('latin1');const i=s.indexOf('<?xpacket');
if(i<0){console.log('אין XMP');process.exit()}
const j=s.indexOf('<?xpacket end',i);
console.log(b.slice(i,j>0?j:i+3000).toString('utf8').replace(/[^\x20-\x7E\u0590-\u05FF<>\n=\/'\"-]/g,''));
" "C:/path/to/VIDEO.mp4"
```

בבדיקה אמיתית זה חשף: קובץ שנוצר ב-Canva, שם התבנית המקורית, ומזהי קמפיין של פייסבוק - כלומר הקליפ עבר עריכה ולא ירד ישר מהמקור.

## עקרונות רוחב

1. **ffprobe לפני הכל** - 2 שניות שחוסכות ריצות סרק.
2. **מעט פריימים גדולים עדיף על המון קטנים** - 15 תמונות ב-960px מנצחות 60 תמונות ב-320px.
3. **לוודא שנוצרו קבצים** (`ls`) לפני שקוראים ולפני שמדווחים.
4. **דיוק בניסוח לפי המקור:** "בכתוביות כתוב X" (מתכון 3) לעומת "נראה בפריימים Y" (מתכון 2) - המשתמש צריך לדעת מאיפה כל עובדה.
