הורדת סרטונים עם קלוד - סקיל להתקנה
======================================

מה זה?
הסקיל מלמד את קלוד להוריד סרטונים מיוטיוב ומעוד מאות אתרים
(טיקטוק, אינסטגרם, פייסבוק ועוד): וידאו מלא, אודיו בלבד כ-mp3,
כתוביות מוכנות (תמלול מיידי!), או רק קטע מסוים מתוך סרטון.
בפעם הראשונה קלוד יתקין בשבילכם (בליווי מלא) כלי חינמי בשם
yt-dlp שעושה את העבודה.

איך מתקינים את הסקיל? (3 צעדים)
1. חלצו את הקובץ שהורדתם (קליק ימני > Extract All / חלץ הכל).
2. העתיקו את התיקייה video-download לתוך תיקיית הסקילים של קלוד:
   בווינדוס:  C:\Users\<שם המשתמש שלכם>\.claude\skills
   במק:       /Users/<שם המשתמש שלכם>/.claude/skills
   (אם תיקיית skills לא קיימת - פשוט צרו אותה)
3. סגרו ופתחו מחדש את Claude Code.

איך משתמשים?
מדביקים קישור וכותבים בשפה חופשית, למשל:
   "תוריד לי את הסרטון הזה: <קישור>"
   "רק את האודיו בתור mp3"
   "תוריד את הכתוביות של הסרטון ותסכם לי אותו"
   "תוריד רק את הדקות 12 עד 14"

בפעם הראשונה קלוד יציע להתקין את yt-dlp - תגידו כן (לוקח
דקה-שתיים, פעם אחת בלבד). מהפעם השנייה הוא ניגש ישר להורדה.

טיפ: משתלב מצוין עם סקיל "ניתוח וידאו" - מורידים כאן, מנתחים שם.

בהצלחה!
