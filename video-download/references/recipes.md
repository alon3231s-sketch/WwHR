# מתכוני הורדה - כל הפקודות

כל המתכונים נבדקו בהורדות אמיתיות. `yt-dlp` בפקודות = הערך מ-`ytdlp_path` ב-state.json (אם שם נתיב מלא - להשתמש בו).

**כל הפקודות כאן הן bash** - להריץ בכלי ה-Bash של קלוד (עובד גם בווינדוס). לא להדביק אותן ב-PowerShell - שם `$HOME` ו-`&&` מתנהגים אחרת.

**איפה שומרים:** תוצר שהמשתמש ביקש → תיקיית ההורדות שלו. `%(title)s` בתבנית השם נותן את שם הסרטון האמיתי.

```bash
DL="$HOME/Downloads"
```

**כלל כפול-בדיקה:** אחרי כל הורדה - `ls -lh` על הקובץ. שם + גודל = הוכחה. בלי זה לא מדווחים "הורדתי".

---

## מתכון 1 - מידע בלי הורדה (מהיר, תמיד ראשון בסרטון ארוך)

לפני שמורידים סרטון של שעה - לבדוק מה הוא בכלל:

```bash
yt-dlp --skip-download --print "%(title)s | %(duration)s sec | %(uploader)s | %(view_count)s views" "URL"
```

לרשימת האיכויות הזמינות: `yt-dlp -F "URL"` (שימושי כשמתלבטים על גודל מול איכות).

## מתכון 2 - וידאו מלא

איכות מיטבית (דורש ffmpeg למיזוג וידאו+אודיו). `--merge-output-format mp4` חשוב - בלעדיו המיזוג יכול לצאת webm, והמשתמש מצפה ל-mp4 שנפתח בכל נגן:

```bash
yt-dlp --merge-output-format mp4 -o "$DL/%(title)s.%(ext)s" "URL"
```

מוגבל ל-1080p (קבצים שפויים - ההבדל מ-4K לרוב לא מורגש במסך רגיל):

```bash
yt-dlp -f "bv*[height<=1080]+ba/b[height<=1080]" --merge-output-format mp4 -o "$DL/%(title)s.%(ext)s" "URL"
```

בלי ffmpeg (`ffmpeg_available: false` ב-state) - פורמט ממוזג מראש, איכות עד 720p:

```bash
yt-dlp -f "b" -o "$DL/%(title)s.%(ext)s" "URL"
```

עובד אותו דבר עם קישורי טיקטוק, אינסטגרם, פייסבוק, טוויטר/X ומאות אתרים - פשוט מדביקים את הקישור.

## מתכון 3 - אודיו בלבד (mp3)

דורש ffmpeg. מושלם להאזנה או לשליחה לכלי תמלול:

```bash
yt-dlp -x --audio-format mp3 --audio-quality 0 -o "$DL/%(title)s.%(ext)s" "URL"
```

בלי ffmpeg: `yt-dlp -f "ba" -o "$DL/%(title)s.%(ext)s" "URL"` - מוריד את האודיו בפורמט המקורי (לרוב m4a/webm, רוב הנגנים מנגנים).

## מתכון 4 - כתוביות בלבד: תמלול ב-10 שניות

**הקיצור הכי שווה בסקיל.** רוב סרטוני יוטיוב מגיעים עם כתוביות מוכנות - אפשר לקבל תמלול מלא עם חותמות זמן בלי להוריד אף פריים של וידאו:

```bash
yt-dlp --skip-download --write-subs --write-auto-subs --sub-langs he,en,en-orig --sub-format vtt -o "$DL/%(title)s.%(ext)s" "URL"
```

- `--write-subs` = כתוביות שהיוצר העלה (מדויקות), `--write-auto-subs` = אוטומטיות של יוטיוב (סבירות). הפקודה מנסה את שתיהן.
- **שפות תמיד ברשימה מפורשת** (`he,en,en-orig`). לא לכתוב `"en.*"` - הווילדקארד תופס גם עשרות תרגומי-מכונה של אותה שפה, מוריד הצפה של קבצים ולפעמים חוטף חסימת קצב (429). נבדק - זה קורה באמת.
- **התקבל חלק מהשפות?** (ביקשנו עברית+אנגלית, ירדה רק אנגלית) - זו הצלחה חלקית, לא כישלון. למסור את מה שיש ולהגיד במפורש איזו שפה חסרה. לא להריץ שוב את אותה פקודה - התוצאה לא תשתנה.
- **לא ירד כלום?** (`no subtitles for the requested languages`) - לבדוק מה כן קיים: `yt-dlp --list-subs "URL"`, ולהוריד משם שפה שיש. אם אין בכלל - להגיד ביושר ולהציע להוריד אודיו (מתכון 3) לתמלול חיצוני.

קובץ ה-VTT הוא טקסט פשוט - קלוד קורא אותו ישירות ומסכם/מתרגם לפי הצורך.

## מתכון 5 - קטע מסוים מתוך סרטון

דורש ffmpeg. כשצריך רק דקה מתוך הרצאה של שעתיים:

```bash
yt-dlp --download-sections "*00:12:30-00:14:00" -f "bv*[height<=1080]+ba/b" -o "$DL/%(title)s - section.%(ext)s" "URL"
```

הפורמט: `*HH:MM:SS-HH:MM:SS`. אפשר גם מהתחלה: `"*0-90"` (90 השניות הראשונות).

## מתכון 6 - פלייליסטים וכמה סרטונים

```bash
# כמה סרטונים ראשונים מפלייליסט (לא את כולו בטעות!)
yt-dlp --playlist-items 1-5 -o "$DL/%(playlist_index)02d - %(title)s.%(ext)s" "PLAYLIST_URL"
```

**לפני פלייליסט שלם** - לבדוק כמה יש בו: `yt-dlp --flat-playlist --print "%(title)s" "PLAYLIST_URL" | wc -l`, להגיד למשתמש כמה סרטונים ומה נפח משוער, ורק אחרי אישור להוריד הכל (להשמיט את `--playlist-items`).

קישור לסרטון שהוא חלק מפלייליסט (`&list=` בכתובת) מוריד כברירת מחדל רק את הסרטון עצמו - זו ההתנהגות הרצויה.

## מתכון 7 - עדכון yt-dlp

יוטיוב והאתרים משתנים כל הזמן; yt-dlp מתעדכן בהתאם. כששגיאות מוזרות מופיעות - קודם מעדכנים:

```bash
# הותקן דרך winget:
winget upgrade --id yt-dlp.yt-dlp --accept-package-agreements --disable-interactivity
# הותקן דרך brew:
brew upgrade yt-dlp
# הותקן בהורדה ישירה (נתיב מלא ב-state):
"$YTDLP_PATH" -U
```

אחרי עדכון - לעדכן את `ytdlp_version` ב-state.json.

## טבלת תקלות

| שגיאה | מה זה | פתרון |
|---|---|---|
| `Sign in to confirm you're not a bot` | יוטיוב חוסם זמנית | לעדכן (מתכון 7), לחכות כמה דקות, לנסות שוב |
| `HTTP Error 403` | גרסה ישנה מול אתר שהשתנה | לעדכן (מתכון 7) |
| `HTTP Error 429` | יותר מדי בקשות ברצף | לחכות דקה-שתיים; בכתוביות - לצמצם את רשימת השפות |
| `Video unavailable` / `Private video` | סרטון פרטי/מחוק/מוגבל | אין פתרון בסקיל - להגיד ביושר. סרטונים פרטיים והגבלת גיל דורשים התחברות לחשבון, מחוץ לתחום |
| `Requested format is not available` | האיכות המבוקשת לא קיימת | `yt-dlp -F "URL"` לרשימה, לבחור פורמט קיים |
| ההורדה נתקעת באמצע | רשת | להריץ שוב את אותה פקודה - yt-dlp ממשיך מאיפה שעצר |

## אחרי ההורדה

- לדווח: שם קובץ מדויק, גודל, ואיפה הוא.
- אם המשתמש רצה "לדעת מה יש בסרטון" ולסקיל האח [[video-analysis]] יש state מותקן - להציע לנתח את הקובץ שהרגע ירד.
- קבצי בדיקה זמניים - למחוק. תוצרים של המשתמש - לא נוגעים.
